# 🚀 Website Starter

A clean, fast, **one-page business website** — no frameworks, no build step, no dependencies. Just HTML and CSS you can edit and publish in minutes.

Great for a small business, freelancer, café, studio or landing page.

## What's inside

- `index.html` — the page (hero, services, about, contact)
- `style.css` — one small, modern, responsive stylesheet

## Make it yours

1. Open `index.html` and change the text to your business.
2. Swap the colors in `style.css` (edit the `--brand` variable at the top).
3. Replace the placeholder links and contact details.
4. Upload the two files to your hosting — done.

## Publish it

Upload `index.html` and `style.css` to your web host's `public_html` and you're live.
